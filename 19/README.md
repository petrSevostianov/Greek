Θα είμαι με τον Γιώργο και την Ιωάννα. = Я буду с Георгием и Иоанной.

Όχι, στο γήπεδο κοντά στο λιμάνι.

Να καλέσουμε ένα ταξί. = Давай вызовем такси.
Όχι, θα πάρω το ποδήλατό μου. = Нет, я возьму свой велосипед.
Σε δέκα λεπτά θα είμαι εκεί. = Через десять минут я буду там.
Εντάξει, πήγαινε.

Έχει αέρα και θα κρυώσεις. = Дует ветер, и ты замерзнешь.
Πήρα, μπαμπά. Τα έχω μέσα στην τσάντα μου. = Я взяла, папа. Их имею внутри сумки моей.
Μην ξεχάσεις τα κλειδιά σου. = Не забудь свои ключи.
Δεν θα είμαι στο σπίτι.
Θα πάω στο σούπερ μάρκετ.

Ναι, και να γυρίσεις νωρίς το βράδυ. = Да, и возвращайся рано вечером.
Γεια. = Пока.

## 3_2017
Ακούστε προσεκτικά!
Καλημέρα!
Την Πέμπτη είναι η μέρα για τον αθλητισμό. = В четверг день спорта.

Θα τη γιορτάσουμε στο σχολείο μας? = Мы будем праздновать это в нашей школе?

Ναι, βέβαια! = Да, конечно!

Θα κάνουμε γιορτή με αθλήματα εκείνη τη μέρα. = Мы устроим праздник с играми в тот день.

Αλήθεια; = Правда?

Πού θα γίνει η γιορτή, στο γυμναστήριο; = Где будет праздник, в спортзале?

Όχι, θα γίνει στο γήπεδο, πίσω από το δημαρχείο. = Нет, он будет на стадионе, за мэрией.

Πολύ ωραία! = Очень хорошо!
    
Τι ώρα πρέπει να είναι εκεί τα παιδιά? = Во сколько детям нужно быть там?

Η γιορτή θα ξεκινήσει στις εννιά το πρωί. = Праздник начнется в девять утра.

Τα παιδιά όμως θα πρέπει να είναι εκεί στις οκτώ και μισή. = Но детям нужно быть там в восемь тридцать.

Θα ξεκινήσουμε λοιπόν από το σχολείο στις οκτώ και τέταρτο. = Итак, мы отправимся из школы в восемь пятнадцать.

Και τι παιχνίδια θα παίξουν τα παιδιά? = И какие игры будут играть дети?
Ποδόσφαιρο και μπάσκετ. = Футбол и баскетбол.

Δεν θα κάνουμε αγώνες τέννης, γιατί χάλασε το δίχτυ. = Мы не будем проводить теннисные соревнования, потому что сетка сломалась.

Δεν πειράζει. = Не беда.

Μετά τη γιορτή τα παιδιά θα γυρίσουν στο σχολείο; = После праздника дети вернутся в школу?

Όχι, η γιορτή θα τελειώσει στις δύο το μεσημέρι. = Нет, праздник закончится в два часа дня.

Θα πάνε λοιπόν σπίτι τους. = Пойдут следовательно домой.

Εντάξει, θα πω στους γονείς να έρθουν να πάρουν τα παιδιά τους από το γήπεδο. = Хорошо, я скажу родителям, чтобы они пришли забрать своих детей со стадиона.


```
γιορτάσουμε = форма глагола γιορτάζω (“праздновать”). Будущее время, 1 лицо множественного числа.
γιορτή = праздник
γίνει = форма глагола γίνομαι (“становиться”). Будущее время, 3 лицо единственного числа.

αθλήματος = игра, спортивное мероприятие

εκείνη = тот, та, то (указательное местоимение)

πίσω = позади
πρέπει = должен

αγώνες = соревнования
χάλασε = форма глагола χαλάω (“ломать”). Прошедшее время, 3 лицо единственного числа.
```
