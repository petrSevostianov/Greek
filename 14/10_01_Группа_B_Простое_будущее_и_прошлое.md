## Глаголы группы В. Упражнения на простое будущее и простое прошлое

```
αόριστος = простое прошедшее время
απλός μέλλοντας = простое будущее время
απλός = простой
```


**1. Вставь правильную форму глагола (αόριστος = простое прошедшее время)**

Пример:  
τηλεφωνώ -> τηλεφώνησα

εγώ τηλεφώνησα
εσύ τηλεφώνησες
αυτός τηλεφώνησε
εμείς τηλεφωνήσαμε
εσείς τηλεφωνήσατε
αυτοί τηλεφώνησαν

εγώ αγάπησα
εσύ αγάπησες
αυτός αγάπησε
εμείς αγαπήσαμε
εσείς αγαπήσατε
αυτοί αγάπησαν

1. Χθες εγώ μπόρησα (**μπορώ**) να πάω στο σινεμά.
2. Η Μαρία τηλεφώνησε (**τηλεφωνώ**) στον φίλο της.
3. Εμείς αγαπήσαμε (**αγαπάω**) πολύ αυτό το μέρος.
4. Ο Νίκος και η Άννα απάντησαν (**απαντώ**) στην ερώτηση.
5. Χθες εσείς μιλήσατε (**μιλάω**) με τη δασκάλα σας; = Вчера вы говорили с учительницей вашей?
6. Τα παιδιά άργησαν (**αργώ**) στο μάθημα.
7. Ο παππούς μου μίσησε (**μισώ**) τα ψέματα.

```
Χθες = вчера
μπορώ = могу
απαντώ = отвечаю
αργώ = опаздываю
μισώ = ненавижу
```

**2. Вставь правильную форму глагола (απλός μέλλοντας = простое будущее время)**

Пример:  
**μπορώ → θα μπορέσω**
```
εγώ θα μπορέσω
εσύ θα μπορέσεις
αυτός θα μπορέσει
εμείς θα μπορέσουμε
εσείς θα μπορέσετε
αυτοί θα μπορέσουν

αγαπάω
εγώ θα αγαπήσω
εσύ θα αγαπήσεις
αυτός θα αγαπήσει
εμείς θα αγαπήσουμε
εσείς θα αγαπήσετε
αυτοί θα αγαπήσουν


```

1. Αύριο εγώ θα μπορέσω (**μπορώ**) να έρθω πιο νωρίς. = Завтра я смогу прийти более рано.
2. Ο Νίκος θα τηλεφωνήσει (**τηλεφωνώ**) στους γονείς του. = Николас позвонит своим родителям.
3. Εμείς θα αγαπήσουμε (**αγαπάω**) πάντα την Ελλάδα. = Мы всегда будем любить Грецию.
4. Τα παιδιά θα απαντήσουν (**απαντώ**) σωστά στις ερωτήσεις. = Дети правильно ответят на вопросы.
5. Εσείς θα μιλήσετε (**μιλάω**) αγγλικά στη δουλειά;
6. Η Μαρία θα αργήσει (**αργώ**) πάλι στο μάθημα;
7. Ο Κώστας θα μισήσει (**μισώ**) τη βροχή.

```
αργώ = опаздываю
μισώ = ненавижу
νωρίς = рано
πιο = более
πάντα = всегда
σωστά = правильно
```


**3. Выбери правильную форму (αόριστος или απλός μέλλοντας)**

1. Χθες αγάπησα (**αγάπησα / θα αγαπήσω**) πολύ την ταινία. = Вчера я очень полюбил фильм.
2. Αύριο θα μιλήσω (**μίλησα / θα μιλήσω**) με τον γιατρό. = Завтра я поговорю с врачом.
3. Χθες μπορέσαμε (**μπορέσαμε / θα μπορέσουμε**) να φτάσουμε στην ώρα μας. = Вчера мы смогли прийти вовремя.
4. Τα παιδιά θα απαντήσουν (**απάντησαν / θα απαντήσουν**) στις ερωτήσεις του δασκάλου αύριο. = Дети ответят на вопросы учителя завтра.
5. Χθες η Μαρία τηλεφώνησε (**τηλεφώνησε / θα τηλεφωνήσει**) στη μητέρα της. = Вчера Мария позвонила своей маме. 
6. Εμείς αργήσαμε (**αργήσαμε / θα αργήσουμε**) στο μάθημα χθες = Мы опоздали на урок вчера.


```
ταινία = фильм
ώρα μας = наше время = вовремя
```

**4. Заполни таблицу спряжением глаголов (αόριστος и απλός μέλλοντας)**

**5. Переведи с русского на греческий (используй αόριστος)**

1. Вчера я смог прийти на вечеринку. = Χθες μπόρεσα να πάω στο πάρτι.
2. Он ответил на все вопросы. = Αυτός απάντησε σε όλες τις ερωτήσεις.
3. Они говорили по-гречески весь вечер. = Αυτοί μίλησαν ελληνικά όλο το βράδυ.
4. Мы любили эту песню. = Εμείς αγαπήσαμε αυτό το τραγούδι.
5. Она позвонила своей подруге. = Αυτή τηλεφώνησε στη φίλη της.
6. Ты улыбнулся, когда увидел меня. = Εσύ χαμογέλασες όταν με **είδες**.

```
песня = τραγούδι
улыбаюсь = χαμογελώ
όταν = когда
```

**6. Переведи с русского на греческий (используй απλός μέλλοντας = простое будущее время)**

1. Завтра я смогу помочь тебе. = Αύριο θα μπορέσω να σε βοηθήσω.
2. Он ответит на твое письмо. = Αυτός θα απαντήσει στο γράμμα σου.
3. Мы будем говорить по-испански. = Εμείς θα μιλήσουμε ισπανικά.
4. Они всегда будут любить эту страну. = Αυτοί θα αγαπήσουν πάντα αυτή τη χώρα.
5. Она позвонит мне вечером. = Αυτή θα μου τηλεφωνήσει το βράδυ.
6. Ты улыбнешься, когда увидишь меня.

```
всегда = πάντα
страна = χώρα
```


**7. Исправь ошибки в предложениях**

1. Χθες θα μιλούσα με τον φίλο μου. → Χθες μίλησα με τον φίλο μου.
2. Ο Νίκος απαντήσω στην ερώτηση. → Ο Νίκος απάντησε στην ερώτηση.
3. Τα παιδιά θα αγαπήσαν το νέο τραγούδι. → Τα παιδιά αγαπήσαν το νέο τραγούδι. = Дети полюбили новую песню.
4. Εμείς μπόρεσαμε να πάμε διακοπές.
5. Η Μαρία θα τηλεφώνησε στον αδερφό της.
6. Εσύ χαμογέλασες όταν θα με δεις.

```
διακοπές = каникулы
```
